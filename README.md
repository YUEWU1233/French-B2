# Répertoire · 法语 B2 词卡

把见过的法语，变成自己的表达。

Répertoire 是一个面向法语 B2 学习者的轻量词卡应用。通过法中翻卡、双语例句和间隔复习，帮助学习者积累词汇、理解搭配，并将表达用于阅读、口语和写作。

项目使用原生 HTML、CSS 和 JavaScript 构建，内置 **1,027 张词卡**，无需注册账号或配置后端，可在电脑、手机浏览器中使用。

## 功能

- **法中翻卡**：正面显示法语，翻面查看中文释义及必要的语法提示。
- **双语例句**：按需展开法语例句，翻面后显示例句中文。
- **直接评分**：在卡片任意一面选择“还没记住”“记住了”或“很熟悉”。
- **间隔复习**：根据自评结果安排下一次复习，优先展示到期卡片。
- **多维筛选**：按主题、单词／词组／表达、学习分层筛选，支持中法文搜索和忽略重音搜索。
- **收藏与词库**：收藏难词，单独复习收藏，或浏览完整词库。
- **法语朗读**：朗读词条与例句，使用设备提供的法语语音。
- **自动保存**：学习进度和收藏保存到当前浏览器。
- **链接分享**：部署后分享网站链接，每位使用者独立记录学习进度。

## 快速开始

下载项目后，直接用浏览器打开 `index.html` 即可使用。

也可以在项目目录启动本地静态服务：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。项目没有 npm 依赖，不需要安装或构建步骤。

## 学习方式

1. 选择主题和学习模式，开始复习。
2. 看法语，回忆含义；需要时翻面或展开例句。
3. 点击卡片下方的熟悉程度按钮，保存结果并进入下一张。

| 评分 | 下一次复习 |
| --- | --- |
| 还没记住 | 10 分钟后 |
| 记住了 | 首次 1 天后；后续按当前间隔乘 2 |
| 很熟悉 | 至少 4 天后；后续按当前间隔乘 3 |

复习间隔最长为 180 天。同一轮中每张卡出现一次，切换筛选或重新载入页面可更新复习队列。“自由练习全部”模式下的评分也会更新复习计划。

支持快捷键：`空格` 翻面，`1`／`2`／`3` 对应三个熟悉程度。快捷键在焦点不位于输入框、选择框或按钮等控件时生效。


## 数据与隐私

进度与收藏使用浏览器的 `localStorage` 自动保存。应用没有账号系统或自建数据服务，不会将学习记录上传到项目服务器。朋友访问同一网址时，记录彼此独立。

数据按浏览器和站点地址分别保存，不会跨设备同步。切换浏览器、更换网址、从本地文件迁移到线上网站，进度不会自动迁移；清除网站数据也会清除记录。当前界面未提供进度导入、导出功能。

## 词库与运行说明

词库根据《Le DELF B2》中的内容，按 B2 备考实用性整理，包含“B2备考”“基础衔接”和“主题扩展”三个学习分层。分层属于教学判断，不代表官方逐词等级认证，也不保证等级边界词零遗漏。双语例句为原创教学内容，项目不包含原书 PDF。

网页版采用响应式布局。在线访问需要联网，当前未提供 PWA 离线缓存。朗读效果与可用性取决于设备、浏览器及已安装的法语语音。
