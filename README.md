# Répertoire · 法语 B2 词卡

静态网页，包含 1,027 张词卡、双语例句、收藏、主题筛选、间隔复习和本地备份。手机浏览器可直接使用，不依赖微信或服务器接口。

## 发布到 GitHub Pages

1. 登录 GitHub，新建一个仓库，例如 `french-b2-cards`。使用 GitHub Free 时，请选择 Public，仓库内容与网站将公开。
2. 把本目录的文件上传到仓库根目录。入口文件必须保持为 `index.html`。不要上传整个学习项目，也不要上传原书 PDF、原文提取文件或个人学习备份。
3. 在仓库的 Settings → Pages 中，选择 **Deploy from a branch**，选择 **main / (root)**，保存。
4. 等待部署完成。网址通常为 `https://你的用户名.github.io/french-b2-cards/`，以 Pages 页面显示的地址为准。
5. 手机打开该网址即可学习，也可点击网页的“分享给朋友”转发链接。iPhone 可在 Safari 中添加到主屏幕。

GitHub 官方说明：[创建 Pages 网站](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)、[设置发布来源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 学习进度

每个人的记录分别保存在自己的浏览器中，没有账号和跨设备自动同步。原电脑本地网页与这个网站不是同一个存储位置：先在原网页导出学习备份 JSON，再到新网址导入，即可迁移。请在“全书提取说明与数据备份”中定期备份。

本版本是在线静态网页，没有新增离线缓存。首次访问需要联网。法语朗读依赖设备提供的法语语音。未公开原书 PDF，词卡保留出处页码供用户用自己的书查阅。

## 目录内容

- `index.html`：网页及词库，所有学习功能在浏览器本地运行。
- `avatar.png`：网页图标。
- `全书逐页检查.csv`：词库提取范围记录。
- `.nojekyll`：按静态文件发布。

词库按 B2 备考实用性筛选，含基础衔接与主题扩展，不构成官方逐词等级认证，也不保证等级边界词零遗漏。例句与中文为原创教学内容。
